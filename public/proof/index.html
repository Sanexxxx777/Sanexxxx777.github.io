05 Как я меряю агентовHow I measure agents

Перед выкладкой агентный конвейер прогоняется на фиксированном наборе задач, регресс виден до релиза. Прогоны трассируются: журнал каждого агента, критический путь и время по часам собираются в одну HTML-страницу (Agent Graph Inspector). На задачу считаются стоимость и латентность, у шагов с моделью есть фолбэк на другого провайдера, так работают Content Factory и агенты поиска работы. Что считается «сделано», описано лестницей доказательств в curated-claude-code. Before a release, an agent pipeline runs on a fixed set of tasks, so regressions show up before shipping. Runs are traced: every agent's journal, the critical path and wall-clock time are assembled into one HTML page (Agent Graph Inspector). Cost and latency are counted per task, and model steps have a fallback provider; Content Factory and the job-search agents work this way. What counts as "done" is described by the evidence ladder in curated-claude-code.
