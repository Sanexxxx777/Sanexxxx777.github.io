Данные и приватность

Короткая версия: этот сайт не собирает персональные данные. Нет форм, нет регистрации, нет cookies. Ниже перечислено всё, что сайт узнаёт о посетителе.

Что сайт записывает

  1. Счётчик посещений. При открытии страницы браузер отправляет на наш сервер путь страницы, язык браузера, адрес сайта, с которого перешли, и глубину прокрутки; при нажатии на кнопки со счётчиком передаётся имя кнопки. IP-адрес не записывается, идентификаторов посетителя и cookies нет, поэтому связать записи с человеком нельзя.
  2. Хостинг. Страницы отдаёт GitHub Pages; его серверные логи ведутся по правилам GitHub, нам они недоступны.

Чего сайт не делает

  1. Не ставит cookies и не использует localStorage для слежения (в localStorage хранится только выбранный язык интерфейса).
  2. Не подключает внешние счётчики, шрифты и скрипты: всё лежит на этом же домене. Исключение: на странице curated-claude-code стоит одна картинка-бейдж каталога LaunchBuck.
  3. Не принимает данные через формы. Кнопки «Написать» и «Заказать» открывают ваш мессенджер или почту; текст сообщения на наш сервер не попадает.
  4. Бесплатная проверка сайта на странице /check/ отправляет введённый адрес сайта в изолированный воркер Cloudflare; адрес не сохраняется, результат никому не передаётся.

Data and privacy

Short version: this site collects no personal data. No forms, no sign-up, no cookies. Everything the site learns about a visitor is listed here.

What the site records

  1. Visit counter. When a page opens, the browser sends our server the page path, the browser language, the referring site and the scroll depth; clicking a tracked button sends the button name. The IP address is not stored, there are no visitor identifiers and no cookies, so records cannot be linked to a person.
  2. Hosting. Pages are served by GitHub Pages; its server logs are kept under GitHub's rules and are not available to us.

What the site does not do

  1. No cookies and no localStorage tracking (localStorage holds only the chosen interface language).
  2. No third-party counters, fonts or scripts: everything is served from this domain. One exception: the curated-claude-code page shows one badge image from the LaunchBuck catalog.
  3. No forms. The contact buttons open your messenger or email client; the message text never reaches our server.
  4. The free site check at /check/ sends the address you type to an isolated Cloudflare Worker; the address is not stored and the result is not shared.
