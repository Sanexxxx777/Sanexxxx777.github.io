Данные и приватность

Коротко: на сайте нет регистрации и следящих cookies. Кнопки «Написать» готовят сообщение у вас в браузере и открывают мессенджер или почту; кнопка «Отправить заявку» на странице заявки передаёт текст задачи и ваш контакт мне в Telegram; бесплатная проверка сайта отправляет введённый адрес в изолированный воркер Cloudflare. Ниже перечислено всё, что сайт узнаёт о посетителе.

Что сайт записывает

  1. Счётчик посещений. Пока вы на странице, браузер отправляет на наш сервер данные из списка ниже.

    Записывается:

    • путь страницы и параметры её адреса;
    • язык браузера;
    • сайт, с которого вы перешли;
    • строка браузера (User-Agent);
    • глубина прокрутки;
    • разделы страницы, которые попали на экран;
    • имена нажатых кнопок со счётчиком;
    • время до первого нажатия.

    Не записывается:

    • IP-адрес;
    • cookies;
    • идентификаторы посетителя;
    • текст сообщений.

    Записи счётчика хранятся 90 дней.

  2. Хостинг. Страницы отдаёт GitHub Pages; его серверные логи ведутся по правилам GitHub, нам они недоступны.

Чего сайт не делает

  1. Не ставит cookies и не использует localStorage для слежения (в localStorage хранится только выбранный язык интерфейса).
  2. Не подключает внешние счётчики, шрифты и скрипты: всё лежит на этом же домене. Исключение: на странице curated-claude-code стоит одна картинка-бейдж каталога LaunchBuck.
  3. Бесплатная проверка сайта на странице /check/ отправляет введённый адрес сайта в изолированный воркер Cloudflare; адрес не сохраняется, результат никому не передаётся.

Заявка с сайта

На странице заявки есть кнопка «Отправить заявку». Нажимая её, вы соглашаетесь на обработку данных из этого раздела.

  1. Что уходит: текст задачи, контакт для ответа (Telegram @username или почта), язык страницы и метка, откуда вы пришли (например, «hire»). Имя, телефон и другие поля не запрашиваются.
  2. Куда: через сервер Cloudflare (воркер order-intake) в мой Telegram-бот, который пересылает заявку мне. Серверы Cloudflare и Telegram находятся за пределами России, то есть это трансграничная передача данных.
  3. Что хранится по дороге: ничего из текста. Сервер держит час только случайный ключ заявки и её номер, чтобы повторное нажатие не создало дубль. Журнал запросов с текстом не ведётся.
  4. Зачем и сколько: чтобы ответить вам ценой и сроком. Заявка хранится в моей переписке в Telegram, пока идёт обсуждение и работа, и удаляется по вашей просьбе, как написано ниже.

Переписка и удаление

Если вы написали мне в Telegram или на почту, ваше сообщение хранится только в этом мессенджере или почтовом ящике. Вы в любой момент можете отозвать согласие на обработку переписки и попросить удалить её тем же каналом. Прекращение обработки наступает сразу после просьбы, удаление персональных данных из переписки занимает не больше 30 дней, подтверждение пришлю ответным сообщением.

Data and privacy

In short: no registration and no tracking cookies. The "Write" buttons prepare a message in your browser and open your messenger or email; the "Send request" button on the request page passes the task text and your contact to my Telegram; the free site check sends the address you type to an isolated Cloudflare Worker. Everything the site learns about a visitor is listed here.

What the site records

  1. Visit counter. While you are on a page, the browser sends our server the data listed below.

    Recorded:

    • the page path and query;
    • the browser language;
    • the referring site;
    • the browser string (User-Agent);
    • scroll depth;
    • page sections that came into view;
    • names of tracked buttons you clicked;
    • time to the first click.

    Not recorded:

    • IP address;
    • cookies;
    • visitor identifiers;
    • text of messages.

    Counter records are kept for 90 days.

  2. Hosting. Pages are served by GitHub Pages; its server logs are kept under GitHub's rules and are not available to us.

What the site does not do

  1. No cookies and no localStorage tracking (localStorage holds only the chosen interface language).
  2. No third-party counters, fonts or scripts: everything is served from this domain. One exception: the curated-claude-code page shows one badge image from the LaunchBuck catalog.
  3. The free site check at /check/ sends the address you type to an isolated Cloudflare Worker; the address is not stored and the result is not shared.

Requests sent from the site

The request page has a "Send request" button. By pressing it you agree to the processing described in this section.

  1. What is sent: the task text, a reply contact (Telegram @username or email), the page language and a label for where you came from (for example "hire"). No name, phone or other fields are asked for.
  2. Where it goes: through a Cloudflare server (the order-intake Worker) to my Telegram bot, which forwards it to me. Cloudflare and Telegram servers are outside Russia, so this is a cross-border transfer.
  3. What is kept on the way: none of the text. The server keeps only a random request key and the request number for one hour, so a second click does not create a duplicate. No request log with the text is kept.
  4. Why and how long: to reply with a price and timeline. The request stays in my Telegram chat while we discuss and do the work, and is deleted on request as described below.

Messages and deletion

If you wrote to me on Telegram or by email, your message lives only in that messenger or mailbox. You can withdraw consent to processing at any time and ask for deletion through the same channel: processing stops as soon as you ask, personal data in the messages is deleted within 30 days, and I confirm by reply.
